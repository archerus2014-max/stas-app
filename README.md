# СТАС — спортивный агент

VK Mini App для подбора подходящих видов спорта на основе анкеты пользователя.

## Архитектура

- `frontend/` — интерфейс VK Mini App.
- `backend/` — API и движок спортивных рекомендаций.
- `data/` — структурированная база знаний.
- `tests/` — автоматические тесты.

## Основные принципы

1. Основной расчёт выполняется детерминированным алгоритмом СТАС.
2. Актуальные данные могут обновляться через интернет.
3. Последняя успешная версия данных должна кэшироваться.
4. ИИ используется как вспомогательный интеллектуальный слой, а не как единственный источник расчёта.
5. Все важные внешние данные должны иметь источник и дату проверки.
6. Доступность спортивного направления в Лангепасе хранится отдельно от спортивного профиля.
7. Пользовательский результат должен содержать рейтинг и объяснение причин.
